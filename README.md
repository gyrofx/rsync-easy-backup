# backup-easy-rsync

## Installation

Install the latest release to `/usr/local/bin` (Linux x86_64 and aarch64):

```bash
curl -fsSL https://raw.githubusercontent.com/gyrofx/rsync-easy-backup/main/install.sh | sh
```

Then check that it works:

```bash
rsync-easy-backup --help
```

## Development

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run start
```
